# 翠灯の迷宮 — 星眠りの森

iPhoneのSafariでの縦画面タッチ操作を想定した、オリジナルの小さなダンジョンRPGです。同行者ひとりと10層のランダムな地下庭を一歩ずつ探索し、最深部の「星の種」を持ち帰ります。画像・キャラクター・効果音は独自実装で、既存作品の素材は使用していません。

## 制作について

このゲームは、ユーザーの企画・指示のもと、dotsとOpenAI Codexを用いてAIで作成しました。

## 遊び方

- △：前進、▽：一歩後退、左右：90度回転。PCでは矢印キー / WASD。
- 操作ボタンとその文字では長押し選択を抑止しています。ログや説明文の選択、ページのスクロールとズームは保っています。
- 地図をタップして拡大。歩いた道と周囲のマスを記録します。
- 戦闘はターン制。「翠の一閃」は気力3、「身を守る」は被害軽減と気力 最大2回復。強撃予告を見て判断します。
- 宝箱は結晶・薬・灯りに加え、この冒険だけで使える装備や護符も得られます。取得内容は閉じるまで表示され、「宝箱の履歴」で今回の最大28箱（旧3層の冒険は9箱）を確認できます。旧セーブで開けた箱の履歴は復元されません。開封演出はスキップでき、端末の縮小モーション設定では省略します。
- 箱は苔木（70%・結晶18–33）、月銀（25%・26–35）、星金（5%・36–45）。苔木は薬1個・灯り最大10、月銀は薬1個・灯り最大15、星金は薬2個・灯り最大20を得ます。取得済みの履歴や所持品を遡って増やすことはありません。結晶は帰還時のスコア用で、店はありません。
- 最初の新規開封で帰り芽の護符（致命傷を一度だけ体力25で生存）、次の3箱で重複しない装備3種を得ます。通常攻撃+2／敵の被害−1（最低1）／4歩ごとの灯り消費0から1個を装備し、探索中だけ切替できます。以降の箱では追加の薬1個に置換。休憩で護符は復活せず、帰還・敗北後の次の冒険へは持ち越しません。メイの小手当と護符が同時なら護符を優先します。
- 仲間の短い会話は操作欄の上に固定した高さで表示。タップして全文と役割を読み返せます。
- 泉は体力・気力を回復。階段で次の層へ進むと体力は最大18、灯りは最大25、気力は上限まで回復します。
- 灯りに応じて迷宮の明るさと遠方の見通しが変わります。地図・文字・操作UIの明るさは変わりません。
- 前進・後退・旋回には短い視点移動演出があります。端末の「視差効果を減らす」等の縮小モーション設定では省略します。
- 灯り10以下では警告が残ります。読み上げ用の通知は警戒帯への移行・残り1・0・回復による解除時に限ります。残り1なら次の一歩で0になり、その一歩から体力4を失います。戦闘中の警告は帰還操作を促しません。
- 灯りは通常一歩につき1減少。0になると一歩につき体力4を失います。回転だけなら減りません。
- 戦闘中以外は「帰路の灯」で戦利品を持って探索を終了できます。守り手を倒して「星の種」を回収し、帰還すれば完全達成。
- 通常敵は苔角の四足獣、大きな翅の蛾、非対称な幹の番人に描き分けています。各層も落葉の回廊、湿った根の底、白い花びらの庭で区別します。
- 最深部のボスは専用の樹冠と「最深部のボス」の表示で区別します。星の種の取得時には案内が開き、帰還まで目標欄に残ります。取得済みの保存から再開した場合も案内します。
- 初期設定は消音。音ボタンで独自合成の足音・剣撃・魔法・防御・宝箱の音を切り替えます。階層ごとに足元の音色と短い反響が変化し、BGMは常時流しません。消音は鳴っている音も停止し、バックグラウンド復帰後は次の操作で再開します。
- 進行はブラウザ内のlocalStorageへ自動保存。同じURL・同じブラウザで再開できます。端末間同期はありません。保存不可の場合は画面に表示します。

## 同行者と休憩

新しい探索では3人からひとりを選びます。同行者は途中で変更できません。選択画面は仲間一覧だけをスクロールし、取消ボタンを常時表示します。3人のオリジナル肖像は選択と会話で共通使用します。

- アオ（門番）：敵の攻撃を毎回2軽減、最低被害1。攻撃力は増えません。
- メイ（薬師）：攻撃・技を2回使うごとに体力6回復。防御や薬では回数が増えず、致命傷を受けた後には回復しません。
- レン（灯技師）：翠の一閃の命中時に追加4ダメージ。ミスや気力不足では発動しません。

4・8層の入口にある休憩所では、それぞれ一度だけ体力・灯り・気力を全回復し、薬を2個補充できます。再訪・再読み込みで補給は復活しません。

以前の3層セーブは、地図と所持品を保って3層の冒険として完走できます。新しい探索を選ぶまで10層へ置き換えません。終了済みの記録はタイトルの「前の冒険の記録」で再表示できます。保存先は従来と同じで、仲間・支援の進行・休憩済み状態も保存します。

## 物語と戦闘

町の夜を照らす「翠灯」を灯し直すため、地下庭の星の種を受け継ぐ旅です。十層は、光を集める上層、水を運ぶ根底、種を育てる最下層へつながります。4・8層は庭守の休憩所で、敵が少ない節目です。仲間が操作や危険を短い会話で伝え、目標と到達した層の物語は「目的と物語」から読み返せます。通常時は長い目的文を常時表示せず、星の種の取得後だけ短い帰還案内を表示します。景観のひと言は各層で一度だけ表示し、表示済み状態を保存します。長い強制会話はありません。

プレイヤーの通常攻撃・翠の一閃はミス5%、クリティカル10%（威力1.5倍・四捨五入）。前の攻撃がミスなら次はミスになりません（その5%分を通常命中にします）。ミスでも行動と技の気力を消費し、生き残った敵は反撃します。敵にはこの抽選を追加していません。抽選状態は自動保存し、同じ保存からの再開で結果が変わらない設計です。

戦闘切替時には古い入力を破棄し、指やキーを離して約0.36秒入力が止まってから新しい操作を受け付けます。逃走ボタンは戦闘操作群の上部に分離しています。戦闘中は敵・HP・予告・行動を優先し、地図・詳細ログ・履歴・物語は「探索情報・地図・戦闘ログ」にまとめます。技は集中・放出・着弾の短い光で表現し、ミスには着弾輪を出しません。音オフや縮小モーション設定でも、結果は文字で確認できます。

## 開発・配信

本体に外部依存はありません。Node.js 22以降とPython 3があれば実行できます。

```sh
npm test
npm run build
python -m http.server 4173 --directory dist
```

`http://localhost:4173` を開きます。`npm run dev` でもソースを直接試せます。`file://` ではES Modulesが読み込めないためHTTPサーバーを利用してください。`dist/` は静的配信可能な完成ビルドです。

GitHub Pagesでは、このリポジトリの `main` ブランチ、`/(root)` を配信元として指定できます。ルートの `.nojekyll` により、ビルドツールなしでHTML/CSS/JavaScriptを配信します。URLのサブパスにも対応する相対参照です。

初回の設定：GitHubの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**。設定操作にはリポジトリ管理権限が必要です。公開状況は同画面とActionsの `pages build and deployment` で確認します。

## 検証

`npm test` は宝箱の重複取得防止・旧セーブと追加履歴の検証・灯り枯渇の処理に加え、1,500マップの連結性・境界・イベント到達性、100シードの旧3層の踏破と帰還、新規3,000マップ、3人×200シードの10層通し進行と休憩・途中保存、戦闘・帰還・死亡・リトライ・保存を検証します。

ブラウザテストは別途Python版Playwrightとブラウザが必要です（ゲームの依存には含みません）。配信サーバー起動後：

```sh
python tests/browser.py
```

`GAME_URL` でテスト対象URLを指定できます。利用可能なChromiumとWebKitを検証し、未導入エンジンは実施不可として報告します。スクリーンショットと結果JSONはGit管理外の `artifacts/` に出力します。

iPhone Safari実機での動作、長時間のバッテリー消費、iOSの音声再開動作は未確認です。クラウド上のChromiumによるモバイルサイズ・タッチエミュレーションは実機検証の代用ではありません。

追加のブラウザ回帰は、ビルド後に `python tests/controls-browser.py` と `python tests/adventure-browser.py` で実行できます。各スクリプトはローカルサーバーを一時起動します。`python tests/expedition-browser.py` は保存マップを経路判定に参照し、状態を書き換えずUI操作だけで開始・保存再開・第10層・休憩所・帰還を通して確認します。`COMPANION=mei` または `ren` で同行者を選べます。人が未知の地図を探索するテストとは異なります。

`python tests/immersion-browser.py` は戦闘画面・攻撃結果・魔法表示・音の生成と停止を個別状態で検証します。音の波形検証は聴感評価ではなく、iPhoneのスピーカーやイヤホンでの臨場感は実機確認が必要です。`python tests/objects-browser.py` は宝箱・泉の描画と壁の遮蔽を確認します。

`python tests/ten-browser.py` は同行者選択と取り消し、4・8層の補給、支援表示、旧セーブの再開を個別状態で検証します。自動攻略の生存率は地図を把握した一定の方針によるもので、初見プレイの難易度保証ではありません。
